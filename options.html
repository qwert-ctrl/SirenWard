FocusGuard

Alles bleibt auf diesem Gerät. Keine Konten, kein Tracking, keine Netzwerkzugriffe.

Gesperrte Websites

Gilt für die Domain und alle Subdomains. Die Sperre sitzt im Browser und greift deshalb auch mit VPN.

    Zeitfreigabe

    Gesperrte Seiten kurz freigeben – mit bewusster Hürde: erst Wartezeit, dann einen Satz abtippen (nur die Buchstaben zählen). Danach sperrt sich die Seite von selbst wieder. Freigeben kannst du im Popup oder auf der Sperrseite.

    YouTube-Ansicht

    Ablenkungen ausblenden, ohne YouTube ganz zu sperren.

    YouTube-Filter

    Gesperrte Videos verschwinden aus Feeds und Suche. Wer sie direkt öffnet, sieht eine Sperrseite.

    Erlaubte Kanäle

      Gesperrte Kanäle

        Gesperrte Stichwörter im Titel

          Tipp: Mehrere Einträge mit Komma trennen. Stichwörter treffen auch Wortteile („game“ trifft „gaming“).

          Sperrmodus

          Während der Sperre kannst du Regeln nur verschärfen: Einträge hinzufügen ja, entfernen oder lockern nein. Die Sperre lässt sich verlängern, aber nicht verkürzen.

          Partner-Code

          Die härteste Variante: Eine andere Person legt einen Code fest. Danach lassen sich Regeln nur noch mit diesem Code lockern – verschärfen geht immer. Der Code wird nur als PBKDF2-Hash gespeichert, nie im Klartext.

          ✓ Partner-Code ist aktiv.

          Zusatzfunktionen

          Alles optional – schalte nur ein, was du brauchst.

          Endet die Zeit vor dem Start (z. B. 22–6 Uhr), gilt sie über Mitternacht.

          Datenschutz & Daten

          FocusGuard speichert nur deine Einstellungen und das Nötigste für Freigaben (heutige Zähler) – lokal im Browser (storage.local, nicht synchronisiert). Kein Verlauf, keine Server; Statistik nur, wenn du sie einschaltest. Die Erweiterung hat technisch keine Möglichkeit, Daten zu versenden.
